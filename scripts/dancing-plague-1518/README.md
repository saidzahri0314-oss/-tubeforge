# The Dancing Plague of 1518 — production package

An 8-minute animated history script, built for a **Krita → Blender** cartoon pipeline.

| File | What's in it |
|---|---|
| [`SCRIPT.md`](SCRIPT.md) | Full narration (1,114 words), 30-shot list with timecodes and camera direction, audio design, retention map |
| [`PIPELINE-krita-blender.md`](PIPELINE-krita-blender.md) | Style bible, Krita→Blender texture round-trip, toon shader recipe, line-art setup, crowd strategy, render settings, 53-day schedule |
| [`SOURCES.md`](SOURCES.md) | Every factual claim graded ✅ / ⚠️ / ❌, with sources and the dissenting historiography |

**Working title:** *The Summer Strasbourg Danced Itself to Death*
**Runtime:** 8:08 · 3840×2160 · 24 fps
**Hook:** A woman dances for six days. The city's cure makes it spread.

## Start here

1. Read `SOURCES.md` first — know which claims are soft before you record VO.
2. Record a scratch VO and cut it to time. The script is written to 138 wpm; your read will differ.
3. Paint the six Krita style frames. **Do not open Blender until these are done.**
4. Build the animatic. If it doesn't work at animatic, it won't work rendered.
