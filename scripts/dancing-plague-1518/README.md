# The Dancing Plague of 1518 — production package

A 10-minute animated history script, built for a **Krita → Blender** cartoon pipeline.

| File | What's in it |
|---|---|
| [`SCRIPT.md`](SCRIPT.md) | Full narration (1,416 words), 66-shot list with timecodes and camera direction, audio design, retention map |
| [`PIPELINE-krita-blender.md`](PIPELINE-krita-blender.md) | Style bible, Krita→Blender texture round-trip, toon shader recipe, line-art setup, crowd strategy, render settings, 58-day schedule |
| [`SOURCES.md`](SOURCES.md) | All 36 factual claims graded ✅ / ⚠️ / ❌, with sources and the dissenting historiography |

**Working title:** *The Summer Strasbourg Danced Itself to Death*
**Runtime:** 10:10 · 3840×2160 · 24 fps
**Hook:** A woman dances for six days. The city's cure makes it spread.
**Turn:** At the midpoint the story appears to end — then Act V reveals it had happened up and down the Rhine for three centuries.

## Start here

1. Read `SOURCES.md` first — know which claims are soft before you record VO.
2. Record a scratch VO and cut it to time. The script is written to 139 wpm; your read will differ.
3. Paint the eight Krita style frames. **Do not open Blender until these are done.**
4. Build the animatic. If it doesn't work at animatic, it won't work rendered.
