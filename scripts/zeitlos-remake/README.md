# Seniorenresidenz „Zeitlos" — Higgsfield remake (720p)

Remake of the 4:12 German tour video (CapCut AI original, 816×464). The script, voices,
timing and scenes stay the same. Every host gets the face from their reference photo
and one identical light-blue scrub uniform.

## What gets fixed

| Part | Time | Host photo | Original outfit → fix |
|---|---|---|---|
| Entrance, resident room, care bed | 0:00–0:40 | photo 3 | light-blue scrubs + stethoscope → universal uniform |
| Bathroom, kitchen, lounge, hallway | 0:40–1:25 | photo 5 | bright-blue sweater → universal uniform |
| Garden, documentation, fitness, physio | 1:25–2:25 | photo 2 | navy scrubs (Nike logo bleed at 2:23) → universal uniform |
| Training shop, bus stop, yoga, pool, dog | 2:25–3:13 | photo 4 | teal scrubs → universal uniform |
| Baking, crafts, day schedule, activity room | 3:13–4:01 | photo 1 | turquoise scrubs, then red blouse + leather jacket → universal uniform |
| Group shot at LVR Klinik | 4:01–4:12 | all five (L→R: 4, 1, 3, 5, 2) | mixed clothes → universal uniform |

**Universal uniform:** soft light-blue (ceil blue) short-sleeve V-neck scrub top with one chest
pocket, matching straight-leg scrub trousers, small plain white clip-on name badge (left chest),
white sneakers. No stethoscope, jacket, sweater or logos.

## Method

Higgsfield **Ad Multiplier** (`model: ad_multiplier`, Seedance 2.5, `mode: video_edit`) replaces
each presenter in the original footage, keeping motion, lip movements, camera and timing.
It accepts 4–30 s per source, so the video is cut at shot boundaries into 12 clips:

| Clip | Range (s) | Images (in `@Image` order) |
|---|---|---|
| c01 | 0–20 | photo3 |
| c02 | 20–40 | photo3 |
| c03 | 40–58 | photo5 |
| c04 | 58–85 | photo5 |
| c05 | 85–109 | photo2 |
| c06 | 109–133 | photo2 |
| c07 | 133–145 | photo2 |
| c08 | 145–169 | photo4 |
| c09 | 169–193 | photo4 |
| c10 | 193–217 | photo1 |
| c11 | 217–241 | photo1 |
| c12 | 241–252.5 | photo4, photo1, photo3, photo5, photo2 |

Per-clip prompts are in `prompts.json` (generated by `build_prompts.py`). Each call:

```json
{"model": "ad_multiplier", "mode": "video_edit", "resolution": "720p", "aspect_ratio": "auto",
 "generate_audio": false, "duration": <ceil(clip seconds)>, "prompt": "<prompts.json[cNN].prompt>",
 "medias": [{"role": "video", "value": "<cNN media_id>"}, {"role": "image", "value": "<photo media_id>"}, ...]}
```

Outputs are silent. `pipeline.sh assemble` joins them at 1266×720 / 30 fps and puts the
original German audio back, so lip-sync and narration match the source exactly.

```bash
./pipeline.sh chunk    original.mp4 chunks/            # c01..c12
./pipeline.sh assemble original.mp4 edits/ final.mp4   # expects e01..e12 from Higgsfield
```

## Quality check

Inspect a frame from every edited clip against its reference photo: face match, the same uniform
shade, no stethoscope or logo, and residents/props unchanged. Retry a failed clip once.

## Cost

Seedance 2.5 at 720p preflights at **7 credits / second** (70 credits for 10 s). The full 252.5 s
is about **1,770 credits** for one pass, plus any retries. Ad Multiplier's exact price is
confirmed with a `get_cost` preflight on the first uploaded clip before anything is spent.

`transcript_de.txt` is a machine transcript (Whisper small) of the original narration, for reference.
